# Mineiro Prime Digital

Crie um website profissional, moderno, responsivo e visualmente atraente para o restaurante O Mineiro Prime, localizado na Rua Antônio Carlos, 282, Consolação, São Paulo - SP.

O estabelecimento é um restaurante e bar especializado em culinária brasileira/mineira, com ambiente descontraído e foco em comida, bebidas e experiência presencial.

OBJETIVO DO SITE
Criar uma presença digital profissional para o restaurante, facilitar o contato dos clientes, apresentar o estabelecimento, destacar seus pratos e direcionar visitantes para telefone, Instagram e localização.

ESTILO VISUAL
- Visual inspirado na culinária mineira e brasileira.
- Aparência moderna, mas com elementos rústicos e acolhedores.
- Tons quentes e naturais.
- Tipografia elegante e fácil de ler.
- Fotografias grandes de comida brasileira, carnes, porções, bebidas e ambiente de restaurante.
- Animações suaves ao rolar a página.
- Design totalmente responsivo para celular, tablet e desktop.

ESTRUTURA

1. HEADER
Logo/nome "O Mineiro Prime".
Menu:
Início
Sobre
Cardápio
Galeria
Localização
Contato

Botão destacado: "Entrar em contato".

2. HERO
Imagem grande de comida brasileira/mineira.

Título:
"Sabor mineiro no coração de São Paulo"

Subtítulo convidando o visitante a conhecer o restaurante.

Botões:
"Conheça nosso cardápio"
"Como chegar"

3. SOBRE
Apresentação do O Mineiro Prime.
Não invente datas, prêmios ou informações históricas que não tenham sido fornecidas.

Destaque:
- Culinária brasileira/mineira
- Ambiente descontraído
- Opções de comidas e bebidas
- Localização na Consolação

4. CARDÁPIO
Criar uma seção visual para categorias como:
Pratos
Porções
Carnes
Bebidas
Sobremesas

IMPORTANTE:
Não inventar nomes, preços ou ingredientes de pratos.
Utilizar conteúdo demonstrativo claramente marcado para posteriormente ser substituído pelo cardápio oficial.

5. GALERIA
Criar uma galeria moderna com espaço para fotos reais do restaurante, pratos, bebidas e ambiente.

6. AVALIAÇÕES
Criar uma área preparada para avaliações reais de clientes.
Não inventar avaliações ou nomes de clientes.

7. LOCALIZAÇÃO
Endereço:
Rua Antônio Carlos, 282
Consolação
São Paulo - SP
CEP 01309-010

Adicionar espaço para integração com Google Maps.

8. CONTATO
Telefone:
(11) 3284-1570

Instagram:
@omineiroprime

Criar botões para telefone e Instagram.

9. FOOTER
Nome do restaurante
Endereço
Telefone
Instagram
Copyright

REQUISITOS TÉCNICOS
- HTML semântico.
- CSS moderno.
- JavaScript apenas quando necessário.
- Mobile-first.
- SEO básico.
- Meta title e description.
- Open Graph.
- Botões com estados hover.
- Navegação suave.
- Menu mobile.
- Imagens com lazy loading.
- Código organizado e fácil de editar.
- Boa acessibilidade.
- Não inventar informações comerciais.
- Não usar textos genéricos em inglês.
- Todo conteúdo deve estar em português brasileiro.

O resultado deve parecer um site comercial real pronto para ser apresentado ao proprietário como demonstração.
